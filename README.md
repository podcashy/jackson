# Jack Interiors & Fittings

Official web application and digital portfolio for **Jack Interiors & Fittings**, a premier architectural finishing, roofing, gypsum, joinery, and interior design firm based in Nairobi, Kenya.

## 📍 Location
* **Address:** Avon Centre, Enterprise Road, Industrial Area – Nairobi
* **Contacts:** 0703 894 897 / 0728 275 840

## 🛠️ Features & Services
* **Durable Roofing & Gutters:** High-performance roofing installations and heavy-gauge box profile gutters.
* **Gypsum Ceilings:** Modern bulkheads, recessed LED lighting troughs, and decorative cornices.
* **Doors & Joinery:** Custom hardwood entrance doors and architectural woodwork.
* **Bespoke Interiors:** Fitted wardrobes and custom kitchen cabinetry.

## 🚀 Hosting & Deployment
* Hosted and deployed continuously via **Netlify Pages** linked directly to this GitHub repository (`jackson`).

## 📂 Project Structure
* `index.html` – Homepage overview
* `roofing.html` – Roofing & gutter systems
* `gypsum.html` – Ceiling solutions
* `doors.html` – Joinery & doors
* `interiors.html` – Cabinetry & wardrobes
* `gallary.html` – Video walkthroughs
* `contact.html` – Inquiry & interactive map location
* `style.css` – Executive stylesheet
* `d/` – Subfolder containing all project photos (`d1.jpg`, `d2.jpg`, etc.)
* `v/` – Subfolder containing all project videos (`v1.mp4`, `v2.mp4`, etc.)
